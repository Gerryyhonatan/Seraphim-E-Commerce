#Seraphim E-Commerce

Ini adalah aplikasi e-commerce yang digunakan untuk berjualan pakaian ataupun outfit dengan tema fashion e-commerce. Didalam aplikasi ini terdapat payment gateway dan juga shipping method. Aplikasi ini berguna untuk membeli pakaian dengan cara pembayaran dan pemesanan yang mudah.

##Tech Stack: 
- Frontend: Next.js
- Backend: Python
- Database: PostgreSql
- Cache: Redis
- Infra: Docker
